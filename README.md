# 4DのORDAイベント：イベント駆動ロジックによるデータ操作の制御

ORDA Events in 4D: Controlling Data Operations with Event-Driven Logic (Technical Note 26-03): Japanese edition.

4D 21で導入されたORDAイベントは、エンティティの作成・変更・保存・削除に応じて自動的に実行されるデータクラスの関数で、従来のトリガーに代わるモダンな仕組みです。このテクニカルノートでは、7種類のイベントの特徴と使い分け、従来のトリガーとの違い、そしてトリガーからORDAイベントへの移行方法を解説します。付属のデモは受注・在庫管理アプリケーションで、在庫チェック、金額の自動計算、注文の検証をORDAイベントで実装しています。

This is the Japanese edition of 4D Technical Note 26-03 and its demo: ORDA events, how they compare with classic triggers, and how to migrate. The demo is an order and stock management application.

## Demo

- 4D version: 4D 21
- Open `demo/ORDAEvents/Project/ORDAEvents.4DProject`.
- Languages: English, Japanese. The UI follows the system language; the XLIFF files are in `Resources/<lang>.lproj/`.
- On startup the main window opens without blocking (File > Run Demo brings it back). When the data file is empty, the sample data for the current language is imported first.

### Demo data

The data file is not included. On first launch, `Resources/<lang>.lproj/data.sql` is imported into the empty data file.
The Japanese data has Japanese client names, comments and product descriptions, and prices in yen (1 USD = 150 JPY,
rounded to ¥100). Both scripts describe the state before the four tests in the note, so the tests can be replayed.
They are generated by `data/ORDAEvents/make_seed.py` from the author's original export, kept in `data/ORDAEvents/export/`.

## Differences from the original

- The test walkthrough uses the Japanese demo: Japanese UI labels, client names, yen amounts and dates.
- The screenshots (fig-01–03, fig-05–12) are retaken from the Japanese demo; the workflow diagram (fig-04) is redrawn with Japanese labels.
- Demo: UI, alerts and the entity-class messages are localised with XLIFF; status and payment values are stored in English and displayed in the UI language. The class code in the demo therefore differs slightly from the code printed in the note.
- Demo: `Product.Price` and `Order.Price` are Long Integer (yen totals), the startup is non-blocking, and "Delete Order" with no selection only shows an alert.

## Editing and rebuilding

The PDF is generated from plain-text sources. Edit them and run `make`.

| File | What |
|---|---|
| `src/ja.md` | Translated body text. **Don't touch code blocks** (`make check` verifies them). |
| `figures/fig-NN.ja.txt` | Text drawn in figure NN. Line N corresponds to line N of `fig-NN.en.txt`: an identical line keeps the original, an empty line erases it. |
| `figures/layout/fig-NN.json` | Per-label overrides for size, weight, alignment and position; `"replace"` uses a ready-made image |
| `glossary.md` | Terminology |

```sh
make            # check → figures → build/26-03_ORDAEvents_ja.pdf
make check      # code blocks unchanged, figure references complete
make review     # contact sheets of the figures (build/contact-N.png)
make release-assets
```

Requirements: Python 3, Google Chrome, CJK fonts, and Tesseract (only needed for re-extraction).
See the [localisation template](https://github.com/miyako/4d-technote-localisation-template) for the full workflow.
